## Methodology

Closed model: 50 concurrent clients for 30s, each sending the next request as soon as
the previous one answers. 200 wallets (1000.00 BRL each); 20% of requests hit
ONE hot wallet; 5% re-send an already-sent request (idempotent replay).
Mix: 70% BET 10.00, 25% WIN 5.00, 5% LOSS. Outbox backlog sampled from PostgreSQL every 500 ms.
